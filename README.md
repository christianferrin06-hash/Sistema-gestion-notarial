# Sistema de Gestión Notarial

Aplicación desarrollada en C++ para la administración y organización de documentos notariales. El sistema permite registrar, consultar, modificar, eliminar y ordenar distintos tipos de documentos mediante una interfaz de consola.

## Descripción

Este proyecto fue desarrollado como parte de mi formación en Ingeniería en Sistemas con el objetivo de aplicar conceptos avanzados de Programación Orientada a Objetos, manejo de excepciones, plantillas y estructuras dinámicas de datos.

El sistema simula el funcionamiento básico de una oficina notarial mediante la gestión de diferentes tipos de documentos y el control de acceso mediante autenticación de usuarios.

## Tecnologías Utilizadas

* C++
* Programación Orientada a Objetos (POO)

## Funcionalidades

### Gestión de Documentos

* Registro de nuevos documentos.
* Consulta de documentos por número.
* Modificación de información de documentos.
* Eliminación de documentos.
* Listado completo de documentos registrados.

### Tipos de Documentos Soportados

* Contratos
* Testamentos
* Facturas
* Escrituras Públicas
* Poderes Notariales
* Declaraciones Juramentadas

### Organización de Información

El sistema permite ordenar los documentos por:

* Número de documento.
* Tipo de documento.
* Fecha.
* Calificación.

### Seguridad

* Inicio de sesión mediante autenticación de usuarios.
* Control de acceso previo al uso del sistema.

### Validaciones

* Validación de entradas de usuario.
* Prevención de números de documento duplicados.
* Manejo de errores mediante excepciones.
